## Summary

Standardized surveys of 147 rocky-shoreline transects along the Chilean coast between 18° S (Arica y Parinacota) and 43° S (Los Lagos), carried out by the Red de Observadores de Aves y Vida Silvestre de Chile (ROC) between 9 and 23 February 2025, were analyzed with a Bayesian zero-inflated negative binomial model (`brms`) to estimate the non-breeding Surfbird population along the rocky coast of continental Chile north of 43° S (median ≈ 45,000 individuals; 95% CrI ≈ 20,000–107,000).

## Repository structure

```
code/surfbird_analysis.R      full pipeline: data prep -> model -> predictions -> Table 1 -> Figure 1
data/                         input data (see data/README.md)
outputs/                      generated by the script (Table 1, Figure 1, model-ready data, sessionInfo)
```

## Data

| File | Description |
|---|---|
| `data/eBirdDataAbr25.csv` | eBird export of the project account (all shorebird checklists) |
| `data/ListasCCAP2025.csv` | Transect metadata for the surveyed checklists (semicolon-delimited): checklist ID, transect ID, region, km walked, coordinates |
| `data/TablaMareasRocosos.csv` | SHOA predicted tide heights used to interpolate tide height at survey time |
| `data/PlayasRocas.kml` | Mapped rocky shoreline segments used to build the 500 m prediction grid |

`outputs/surfbird_model_data.csv` is the zero-filled, model-ready dataset (one row per surveyed transect: date, time, region, coordinates, km walked, survey duration, number of observers, tide height, Surfbird count). Column definitions are in `data/README.md`.

## Reproducing the analysis

Requires R ≥ 4.5 and a working Stan toolchain (`rstan` or `cmdstanr`).

```r
install.packages(c("tidyverse", "lubridate", "zoo", "scales", "sf", "brms",
                   "rnaturalearth", "rnaturalearthdata", "ggspatial", "ggrepel", "cowplot"))
# ne_states() additionally needs rnaturalearthhires:
# remotes::install_github("ropensci/rnaturalearthhires")

source("code/surfbird_analysis.R")
```

* The script prints sanity checks (number of checklists, total count, survey dates, number of prediction points) against the values reported in the paper.
* Model fitting (4 chains × 10,000 iterations, `adapt_delta = 0.99`) takes several minutes to tens of minutes depending on hardware.
* Re-fitting may give slightly different posterior summaries than those in the paper (Stan/`brms` version and platform differences, 5 divergent transitions were reported). The fitted model used for the paper is archived on Zenodo; set `RERUN_MODEL <- FALSE` in the script and place it at `outputs/mod_bayes.rds` to reproduce the reported estimates exactly.
